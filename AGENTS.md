# Agent Instructions

Personal notes and summaries on videos from [Defiant Gatekeeper](https://www.youtube.com/@DefiantGatekeeper).

## How to add a new video

When a new video transcript is added (e.g. `transcript-original.txt` at the repo root), do the following:

1. Create a folder named after the video title, all lowercase with hyphens (e.g. `full-course-on-stock-investing-2-hours/`)
2. Move the transcript into that folder as `transcript-original.txt`
3. Create `notes.md` — detailed notes with timestamps linking to specific video sections (`https://youtu.be/<VIDEO_ID>?t=<seconds>`)
4. Create `cheatsheet.md` — quick reference with formulas, thresholds, and decision rules
5. Link the video from the README, following the same format as existing video sections
